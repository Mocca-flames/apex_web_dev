# Coverage Mobile Overlay — Implementation Plan

**Date:** 2026-05-18
**Owner:** Kilo
**Scope:** `css/components.css` — one media-query block change + one new tablet block

---

## Context

The Coverage section already has the correct HTML structure:

```html
<div class="coverage-slide" data-index="0">
  <div class="coverage-slide__content">
    <h3 class="coverage-slide__title">South Africa</h3>
    <p class="coverage-slide__text">...</p>
  </div>
  <div class="coverage-slide__frame">
    <img class="coverage-slide__map" src="/experiment/sa.webp" ...>
  </div>
</div>
```

`coverage.js` already drives `is-active` / `is-leaving` transitions identically to `services.js`. The only missing piece is the **mobile CSS** — currently the `@media (max-width: 768px)` block stacks content above the image in a normal document flow. The request is to **overlay** the text on the image:

> **Text top** (country name) + **text bottom** (description) → on top of the map image

### 1 — Replace `coverage-slide` mobile rule (≤768px)

**Before:**
```css
@media (max-width: 768px) {
  .coverage-slide {
    flex-direction: column;
    padding: var(--space-8) var(--space-6) var(--space-8) 56px;
    gap: var(--space-12);

  .coverage-progress__labels { display: none; }
}
```

**After:**
```css
@media (max-width: 768px) {

  .coverage-slide {
    flex-direction: column;
    justify-content: center;
    padding: 0;
    gap: 0;
  }

  /* Image fills the entire sticky viewport */
  .coverage-slide__frame {
    flex: 1;
    position: relative;
    width: 100%;
    height: 100%;
    max-height: none;
  }

    border-radius: 0;
  }

  /* Hide rail on mobile — text overlays the map instead */
  .coverage-progress {
    display: none;
  }

  /* ── Content overlays the map ── */
  .coverage-slide__content {
    position: absolute;

    z-index: 2;
    display: flex;
    flex-direction: column;

      to top,
```

### 2 — Add a new tablet rule (768px–1024px)

Inserted **after** the existing `@media (max-width: 768px)` block and **before** `@media (max-width: 480px)`:

```css
/* ── Tablet — overlay begins, map narrower ── */
@media (min-width: 769px) and (max-width: 1024px) {
  .coverage-slide {
    justify-content: center;
    gap: var(--space-6);
  }

  .coverage-slide__content {
    position: absolute;
    inset: 0;
    z-index: 2;
    display: flex;
    flex-direction: column;
    justify-content: space-between;
    padding: var(--space-10) var(--container-pad);
    pointer-events: none;
  }
  .coverage-slide__content > * { pointer-events: auto; }

  .coverage-slide__title {
    color: var(--apex-white);
    text-shadow: 0 2px 20px rgba(0,0,0,0.5);
    margin-bottom: 0;
    transform: none;
  }
  .coverage-slide:not(.is-active) .coverage-slide__title {
    transform: translateY(-12px);
    opacity: 0;
  }

  .coverage-slide__text {
    color: var(--apex-white);
    text-shadow: 0 1px 10px rgba(0,0,0,0.5);
    /* max-width so long text doesn't span the full frame */
    max-width: 480px;
    background: linear-gradient(
      to top, rgba(0,0,0,0.40), rgba(0,0,0,0.15), transparent
    );
    margin: 0;
    padding-bottom: var(--space-4);
    transform: none;
  }
  .coverage-slide:not(.is-active) .coverage-slide__text {
    transform: translateY(12px);
    opacity: 0;
  }

  .coverage-slide__map {
    object-fit: cover;
  }

  .coverage-progress__labels {
    display: flex;   /* restore rail labels on tablet */
  }
}
```

### 3 — Remove the `transform/opacity` override from `is-leaving` under the new mobile block

Under the ≤768px block the existing `is-leaving` rule already applies globally
(no media-query override), so it needs no change — the overlay rules target
`is-active` and `:not(.is-active)` only, keeping the exit animation working.

## Why each decision is correct

**Map as background, not separate column**  
The map image (`img.coverage-slide__map`) becomes the full-height fill behind the text. This mirrors how the hero section treats its background image and how `services-sticky` treats its `.services-image` column. Users already understand this visual model.

**Title at top via `justify-content: space-between` on a column flex**  
A single flexbox rule (`justify-content: space-between`) on `__content` handles both anchors without absolute-positioning hacks. Title sticks to top, description sticks to bottom.

**`pointer-events: none` on container, `auto` on children**  
The overlay container mustn't intercept scroll or touch events outside the viewport. Only the actual interactive children (none today; future: CTA buttons) get `auto`.

**Text shadows instead of solid background panels**  
Service cards don't use opaque text pills — they use transparent shadows. The same treatment keeps the map visible and the text readable without breaking the cinematic look.

**Tablet = same overlay but labels lumber visible**  
Tablets have enough horizontal space to keep the label rail, while phones benefit from the rail being off-stage to maximise text legibility.

## Acceptance criteria

- [ ] On mobile (≤768px): open page, scroll to Coverage, confirm country name renders **on top of the map image** and description renders on the **bottom of the map image** — no visible layout gap between image boundary and text
- [ ] On tablet (769px–1024px): same, with rail labels still visible to the left
- [ ] All 8 slides cross-fade correctly (tap/label-dot or scroll)
- [ ] No horizontal overflow at 375px / 390px / 428px widths
- [ ] Text contrast ≥ 4.5:1 against the lightest expected portion of the map shadow gradient (manual check with DevTools contrast picker)
- [ ] Safe-area insets respected on iPhone X-style devices (text doesn't sit under notch or home-indicator)
