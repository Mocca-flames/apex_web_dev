# Plan: Coverage Section — Mobile Layout (Title → Image → Text)

## Problem
The Coverage section currently shows images below text (`content div` + separate `frame div`) on mobile.
The Services section already has title → image → subtext on mobile (via `order` property + injected `mobile-img`).
The user wants the same Title-on-top / Image-in-middle / Subtext-on-bottom pattern for Coverage mobile, using separate `/country_mobile/` images.

## Key Architecture Insight
- **Desktop**: Two-column layout; `.coverage-slide__content` (text left) + `.coverage-slide__frame` (map right, `abs inset:0`, `object-fit:contain`)
- **Mobile**: Reset to flex column; `.coverage-slide__content` holds **all three** children stacked: `.coverage-slide__title`, `.coverage-slide__map`, `.coverage-slide__text`
- `coverage.js` controls `is-active` on `.coverage-slide` — inactive are `opacity:0`, so single-cell stacked elements never flash simultaneously
- The `isMobile` flag inside `content.js`' `buildCoverageSlides()` already picks the correct image folder

## Files to Change

### 1. `index.html` — Restructure coverage slide markup (lines 256–349)
Replace each slide's current 2-div structure:

## How Desktop Is Preserved
- `.coverage-slide__content` content-block styles only activate at `@media(max-width:1024px)` — desktop content block width/positioning stays unchanged in the global scope
- `.coverage-slide__frame` and `.coverage-slide__map` desktop styles (`flex:1; height:72vh; position:absolute; inset:0; object-fit:contain`) remain untouched at global scope
- The alignment rule `alignment.css:_38: .coverage-slide__title { margin-inline-start: var(--container-pad); }` still applies on both breakpoints ✅

## Risks / Mitigations
| Risk | Mitigation |
|---|---|
| `.coverage-slide__map` inherits absolute positioning from global CSS | Scope mobile override with `position:relative` + `width:100%` inside `@media(max-width:1024px)` in `alignment.css`. Selector `.coverage-slide.is-active .coverage-slide__map { ... }` has higher specificity than the `.coverage-slide__map` global rule and lives in a later media query — cascade wins. |
| `buildCoverageSlides()` fires after mutation → stale frame divs | `buildCoverageSlides()` rebuilds the entire `.coverage-journey__slides` innerHTML — no stale elements. |
| `.coverage-slide__content` lost on initial HTML load before JS fires | Full structure is in `index.html` — progressive enhancement only. |
| Duplicate `@media(max-width:1024px)` in components.css | Remove the second block (line 1811–2065) — the first block is the authoritative version, unchanged. |
